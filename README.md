# Cloud-Based MCB Trip Monitoring System

## Project Overview
The Cloud-Based MCB Trip Monitoring System is an IoT-based solution designed to detect and monitor MCB (Miniature Circuit Breaker) trip events in real time. The system collects sensor data, sends it to a cloud server, and provides alerts for quick fault detection and monitoring.

## Features
- Real-time MCB trip detection
- Cloud-based monitoring
- REST API integration using Python Flask
- Sensor data collection and processing
- Alert notification system
- API testing using Postman

## Technologies Used
- Python
- Flask
- REST API
- IoT Sensors
- Postman
- ESP32/Arduino (if used)
- Adafruit IO (if used)

## System Workflow
1. Sensors monitor electrical conditions.
2. MCB trip events are detected.
3. Data is sent to the Flask backend through APIs.
4. Data is stored and processed.
5. Alerts are generated when faults occur.
6. Users can monitor the system remotely.

## Project Objectives
- Detect MCB trips automatically.
- Reduce manual monitoring effort.
- Improve fault response time.
- Enable cloud-based remote monitoring.

## Future Enhancements
- Mobile application integration.
- Machine learning-based fault prediction.
- SMS and Email alert notifications.
- Dashboard analytics and reporting.
